- [Mac✓, disassembly] On display changes the agent enumerates online displays; if Sidecar is "the last online display" and not exclusive, it runs a teardown path (likely: session drops). Exclusive mode (Vision Pro Mac Virtual Display style) skips this, but the exclusiveMode defaults override is gated by os_variant_has_internal_ui -> ignored on retail. Client-set configureDisplayExclusiveMode untested; your session logged "Is not SideCar exclusive request".

Recommended approach
- Swift LaunchAgent in the GUI session; dlopen SidecarCore; pick device by identifier (= plist recents UUID); connect with retry/backoff on device-generation; transport=2 when cabled.
- Detect via vendor/product (or SidecarDeviceTypeIdentifier) + connection-generation notify.
- Never remove the last non-Sidecar display: keep a tiny CGVirtualDisplay anchor (or mirror physicals into Sidecar), then disable physicals session-only (SLSConfigureDisplayEnabled/CGSConfigureDisplayEnabled exist [Mac✓]) and make Sidecar main via CGConfigureDisplayOrigin(0,0).
- Dead-man switch: re-enable physicals on Sidecar loss, crash or timeout.
